## SCSS Structure

기능별로 스타일을 분리하여 유지보수성과 재사용성을 고려한 구조로 관리했습니다.

```scss
assets/scss/
├── abstracts/   # Variables, Mixins, Functions
├── base/        # Reset & Global Styles
├── components/  # Component Styles
└── index.scss   # SCSS Entry Point
```

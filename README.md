# Sunkyoung Kim | Web Publisher Portfolio

React 기반으로 제작한 포트폴리오 사이트입니다.

프로필·경력 정보와 프로젝트를 분리된 레이아웃으로 구성했으며,  
React 컴포넌트 구조와 SCSS 모듈화를 통해 재사용성과 유지보수를 고려한 퍼블리싱 구조로 구현했습니다.

🔗 Live  
https://skkim0130.github.io/portfolio-sk/

🔗 Github  
https://github.com/skkim0130/portfolio-sk/

## Tech Stack

- React
- Vite
- SCSS
- GitHub Pages

## Features

- React 컴포넌트 기반 UI 구조
- SCSS 구조 분리 (abstracts/base/components)
- CSS Modules를 활용한 컴포넌트 단위 스타일 관리
- 반응형 웹 기반 레이아웃 구현
- 프로젝트 리스트 및 상세 모달 UI
